## a) Online

Asennetaan Git virtuaalikoneelle. 

```
sudo apt update
sudo apt install -y git
```

Tehdään GitHubiin uusi varasto. Painetaan oikealla ylhäällä olevaa + merkkiä ja sieltä `new repository`.
